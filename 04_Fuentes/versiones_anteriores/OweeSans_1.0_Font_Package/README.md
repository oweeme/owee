# Owee Sans 1.0

Primera fuente funcional de Owee Script.

Archivos:
- OweeSans-Regular.ttf — Linux/escritorio
- OweeSans-Regular.otf — OpenType/CFF
- OweeSans-Regular.woff2 — web
- demo.html — conversor Roman Owee -> Script
- owee-pua-map.json — mapa compartido por fuente/parser/IME

Instalacion Linux (usuario):
1. Copiar OweeSans-Regular.ttf a ~/.local/share/fonts/Owee/
2. Ejecutar fc-cache -fv

PUA: U+E000..U+E03B. Esta es una codificacion privada de Owee 1.0.
