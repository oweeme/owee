Owee Sans 3.0
- Conserva los 60 glifos canonicos de Owee Sans 1.0.
- Los hace visualmente mas grandes y compactos para lectura continua.
- Advance width: 650 unidades.
- Incorpora digitos oficiales Owee 0-9 en U+E040..U+E049.
- No redefine la fonologia ni los IDs silabicos.

Instalacion Deepin/Linux:
mkdir -p ~/.local/share/fonts
cp OweeSans3-Regular.ttf ~/.local/share/fonts/
fc-cache -fv

Luego seleccione 'Owee Sans 3' en la aplicacion.
