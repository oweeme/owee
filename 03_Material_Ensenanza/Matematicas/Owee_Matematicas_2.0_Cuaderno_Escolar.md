# Owee Matemáticas — cuaderno escolar

Números y cuentas en Owee: sistema decimal, glifos numéricos y práctica progresiva. Cada número aparece con su **glifo** y, debajo, su **lectura en Owee**. Las cuentas resueltas de este cuaderno se comprueban automáticamente al generarlo.

**Regla:** se **calcula** con los glifos numéricos y se **lee** con las palabras. Los signos (`+ − × ÷ = < >`) son los internacionales.

## 6. Las operaciones

| Signo | Owee | Idea |
|---|---|---|
| + | `dapa` | sumar, agregar |
| − | `dopo` | restar, quitar |
| × | `kebu` | multiplicar, grupos iguales |
| ÷ | `faku` | dividir, repartir |
| = | `se` | igual |
| > | `pa` | mayor que |
| < | `po` | menor que |
| ≥ | `pa-lo-se` | mayor o igual |
| ≤ | `po-lo-se` | menor o igual |

## 10. Decimales, fracciones y porcentajes

`doto` = coma decimal · `palo` = parte (fracción) · `gabu-palo` = por ciento.

| Decimales | Fracciones | Porcentajes |
|---|---|---|
| [[0.5]] | [[1/2]] | [[10%]] |
| [[1.25]] | [[1/3]] | [[25%]] |

| [[20.08]] | [[7/10]] | [[100%]] |

**Fíjate:** [[1/2]], [[0.5]] y [[50%]] son la misma cantidad.

## 11. Medidas

Se usan las unidades internacionales (m, kg, s, L, °C); Owee aporta los conceptos.

| Concepto | Owee | Unidad |
|---|---|---|
| longitud | `mede dase` | metro (m) |
| masa | `mede gume` | kilogramo (kg) |
| tiempo | `mede tera` | segundo (s) |
| volumen | `mede kopa` | litro (L) |
| temperatura | `mede fure` | grado Celsius (°C) |
| área | `mede gore` | metro cuadrado (m²) |
