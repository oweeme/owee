# Owee Matemáticas — guía completa

**Fuentes:** *Owee Mathematics 1.0* (números y aritmética escolar) y *Owee Matemáticas 2.0* (álgebra a álgebra lineal), unificadas y con las correcciones de auditoría. Todos los números y ecuaciones de los ejemplos se muestran **con el glifo numérico de Owee** y, debajo, su **lectura en Owee**. Los ejemplos numéricos de esta página se verifican automáticamente al generar el sitio: si un cálculo estuviera mal, la página no se genera.

> **Principio:** Owee **no reemplaza** la notación matemática internacional. Los símbolos (`+ − × ÷ = < > ≤ ≥ √ π ∞ % Σ ∫ Δ ! °`) y las letras de variables (x, y, f…) se conservan; Owee aporta el **vocabulario y los numerales**. Primero se compone con raíces existentes; solo lo fundamental recibe raíz técnica propia.

## 0. Dos escrituras para los números

Owee tiene **dos formas** de escribir un número, y conviene no confundirlas:

| Forma | Qué es | Ejemplo para 25 |
|---|---|---|
| **Glifo numérico** | Cifras posicionales, como los dígitos arábigos. Es la que se calcula con ella | [[25]] |
| **Escritura fonética** | El número como palabras Owee, sílaba por sílaba (`du tanu sa`). Es la que se lee en voz alta | `du tanu sa` |

Regla: **se calcula con el glifo numérico y se lee con las palabras.** Los dos describen lo mismo.

## 1. Los diez dígitos

## 3. Decimales, fracciones, porcentajes y orden

### 3.1 Decimales

`doto` es el separador decimal hablado. **Después de `doto` los dígitos se leen uno por uno.** No se convierte `0,25` en una palabra irregular.

| Número y lectura | Número y lectura |
|---|---|
| [[0.5]] | [[3.1416]] |
| [[1.25]] | [[20.08]] |
| [[0.75]] | [[10.5]] |

### 3.2 Fracciones

`palo` = parte. `1/2` se lee «una parte de dos»: `be palo du`. La notación `a/b` se conserva.

| Fracción y lectura | Fracción y lectura |
|---|---|
| [[1/2]] | [[3/4]] |

### 3.3 Porcentajes

`%` se lee `gabu-palo` («parte de cien»). Así, [[50%]] es «cincuenta partes de cien» y [[25%]] es «veinticinco partes de cien». (La guía 1.0 usaba `por`, que el Registro **no** ha adoptado: aquí se sigue la guía 2.0.)

**Ejemplo.** El 25 % de 80: [[80 × 25 ÷ 100 = 20]]. El 10 % de 250: [[250 ÷ 10 = 25]].

### 3.4 Comparar y ordenar

`pa` = mayor, `po` = menor, `se` = igual; con `lo` («o») se forman `pa-lo-se` (≥) y `po-lo-se` (≤).

| Relación y lectura | Relación y lectura |
|---|---|
| [[3 < 7]] | [[9 > 4]] |
| [[5 = 5]] | [[25 < 52]] |
| [[8 ≥ 8]] | [[6 ≤ 9]] |

### 3.5 Cero y números negativos

`cho` es el cero. Owee ya tiene **tres palabras distintas** para tres ideas distintas, y no se confunden:

| Idea | Palabra | Ejemplo |
|---|---|---|
| **Negar** un enunciado | `no` | `kema-no mora` (no hay nada) |
| **Signo** de una cantidad: positivo / negativo | `pa` / `po` (más / menos, escalares) | −5 = `po sa` |
| **Operación**: suma / resta | `dapa` / `dopo` | 3 − 5 = `ga dopo sa` |

Así **el signo negativo es `po`**, la misma palabra con la que Owee dice «menos / menor». (La guía 1.0 usaba la palabra española «negativo», que no es Owee.) La posición lo distingue: `po` al principio o justo después de un operador es un **signo**; `po` entre dos números es una **comparación** (`ga po mu`, 3 < 7).

| Expresión | Lectura |
|---|---|

| [[−12]] | |
| [[3 − 5 = −2]] | |
| [[3 + −5 = −2]] | |
| [[−4 < 2]] | |

## 4. Aritmética en detalle

Las operaciones fundamentales: `dapa` (suma, +), `dopo` (resta, −), `kebu` (multiplicación, ×), `faku` (división, ÷), `se` (igualdad). La resta usa `dopo`; `po` sigue siendo «menos/menor».

### 4.1 Suma (`dapa`)

| Operación |
|---|
| [[2 + 3 = 5]] |
| [[7 + 8 = 15]] |
| [[25 + 14 = 39]] |
| [[120 + 35 = 155]] |
| [[247 + 103 = 350]] |

**Con acarreo: 58 + 67.** (1) Unidades: `8 + 7 = 15`: se escribe 5 y se *lleva* 1. (2) Decenas: `5 + 6 + 1 = 12`: se escribe 2 y se lleva 1. (3) Centenas: se baja el 1. Resultado: [[58 + 67 = 125]]

### 4.2 Resta (`dopo`)

| Operación |
|---|
| [[9 − 4 = 5]] |
| [[18 − 7 = 11]] |
| [[50 − 25 = 25]] |
| [[500 − 125 = 375]] |
| [[1000 − 247 = 753]] |

**Con préstamo: 52 − 27.** (1) Unidades: 2 no alcanza para quitar 7: se *toma prestada* una decena y queda `12 − 7 = 5`. (2) Decenas: ahora 4 − 2 = 2. Resultado: [[52 − 27 = 25]]

### 4.3 Multiplicación (`kebu`)

| Operación |
|---|
| [[2 × 3 = 6]] |
| [[4 × 5 = 20]] |
| [[6 × 7 = 42]] |
| [[12 × 11 = 132]] |

**Por descomposición: 23 × 14.** `23 × 14 = 23 × 10 + 23 × 4`. Primero [[23 × 10 = 230]]; después [[23 × 4 = 92]]; se suman [[230 + 92 = 322]]. Por tanto [[23 × 14 = 322]].

### 4.4 División (`faku`)

| Operación |
|---|
| [[20 ÷ 5 = 4]] |
| [[36 ÷ 6 = 6]] |
| [[100 ÷ 10 = 10]] |
| [[156 ÷ 12 = 13]] |

**Paso a paso: 156 ÷ 12.** (1) ¿Cuántas veces cabe 12 en 15? 1 vez: `1 × 12 = 12`, sobran 3. (2) Se baja el 6: 36. (3) ¿Cuántas veces cabe 12 en 36? 3 veces: `3 × 12 = 36`, sobran 0. Cociente 13: [[13 × 12 = 156]].

### 4.5 Orden de las operaciones

Primero potencias y raíces, luego `kebu` y `faku`, y por último `dapa` y `dopo`; de izquierda a derecha. **Ejemplo:** `2 + 3 × 4`: primero se multiplica [[3 × 4 = 12]] y después se suma: [[2 + 12 = 14]].

### 4.6 Potencias y raíces

`telu` = potencia (exponente), `raku` = raíz. Los exponentes se leen: `n telu m`.

| Operación |
|---|
| [[2 ^ 2 = 4]] |
| [[2 ^ 3 = 8]] |
| [[10 ^ 2 = 100]] |
| [[3 ^ 4 = 81]] |
| [[√16 = 4]] |
| [[√81 = 9]] |

El logaritmo (`loge`) es la operación inversa de `telu`: como [[10 ^ 2 = 100]], log₁₀(100) = 2.

### 4.7 Sistema Internacional y medida

Se conservan los símbolos SI (m, kg, s, K, L); Owee aporta los conceptos: longitud `mede dase`, masa `mede gume`, tiempo `mede tera`, volumen `mede kopa`, temperatura `mede fure`, área `mede gore`.

## 5. Álgebra
<!--vocab Matemáticas|Álgebra-->

| Concepto | Forma Owee | Nota |
|---|---|---|
| variable / incógnita | `bara` / `daku` | La variable puede cambiar; la incógnita es un valor desconocido |
| ecuación | `seka` | Relación que afirma igualdad |
| sistema de ecuaciones | `seka-rela` | Ecuaciones relacionadas; no necesita raíz nueva |
| elemento de conjunto | `seta palo` | Parte/miembro de un conjunto |

**Anatomía de `3x + 5 = 20`:** toda la igualdad es una `seka`; `3x + 5` es una `rebo` (expresión); `3x` y `5` son `teda` (términos); `3` es el `kofa` (coeficiente); `x` es `bara` y, al resolver, `daku`.

### 5.1 Ecuaciones de un paso

Los operadores ya aprendidos funcionan igual. En lectura, `x` se dice `bara`:

```owee
bara dapa ga se mu
bara dopo fo se sa
bara kebu du se be tanu
```

| Ecuación | Solución | Verificación |
|---|---|---|
| `#x + 3 = 7` | `#x = 4` | [[4 + 3 = 7]] |
| `#x − 4 = 5` | `#x = 9` | [[9 − 4 = 5]] |
| `#2x = 10` | `#x = 5` | [[2 × 5 = 10]] |
| `#x ÷ 3 = 4` | `#x = 12` | [[12 ÷ 3 = 4]] |

### 5.2 Ecuaciones de dos pasos: `3x + 5 = 20`

(1) Se quita el 5 de ambos lados: `#3x = 20 − 5 = 15`. (2) Se divide por 3: `#x = 15 ÷ 3 = 5`. (3) Verificación: [[3 × 5 + 5 = 20]].

**Otra: `4x + 7 = 19`.** `#4x = 19 − 7 = 12`, `#x = 12 ÷ 4 = 3`. Verificación: [[4 × 3 + 7 = 19]]. Aquí `4` es `kofa`, `4x` y `7` son `teda`, `4x + 7` es `rebo` y toda la igualdad es `seka`.

### 5.3 Sistema de dos ecuaciones (`seka-rela`)

`#x + y = 10` y `#x − y = 2`. Sumando ambas: `#2x = 12`, luego `#x = 6`. Sustituyendo: `#y = 10 − 6 = 4`. Verificación: [[6 + 4 = 10]] y [[6 − 4 = 2]].

### 5.4 Ecuación con potencia: `x² + 2x + 1 = 0`

Se reconoce `#(x + 1)² = 0`; por tanto `#x + 1 = 0` y `#x = −1`. (Los negativos se leen con `po`, ver 3.5.) La potencia es `telu`; la raíz, `raku`.

### 5.5 Funciones (`funa`, `duno`, `remu`)

Una función asigna a cada valor de entrada (`duno`, dominio) un valor de salida (`remu`, rango). Sea `#f(x) = 2x + 1`:

| Entrada (`duno`) | Cálculo | Salida (`remu`) |
|---|---|---|
| `#0` | [[2 × 0 + 1 = 1]] | `#1` |
| `#1` | [[2 × 1 + 1 = 3]] | `#3` |
| `#2` | [[2 × 2 + 1 = 5]] | `#5` |
| `#3` | [[2 × 3 + 1 = 7]] | `#7` |

### 5.6 Conjuntos (`seta`)

`#A = {1, 2, 3}` es una `seta`; cada número es una `seta palo` (elemento). `#A` tiene [[3]] elementos.

Figuras por número de lados (`número + kado`):

| Concepto | Forma Owee | Nota |
|---|---|---|
| triángulo | `ga-kado` | tres lados |
| cuadrilátero | `fo-kado` | cuatro lados; no implica cuadrado |
| pentágono | `sa-kado` | cinco lados |
| hexágono | `ku-kado` | seis lados |
| área | `sufa mede` | medida de una superficie |
| perímetro | `dore-fese mede` | medida del límite de una forma |
| coordenada | `pose-mede` | posición expresada mediante medida |
| 2D / 3D | `du-dora` / `ga-dora` | número + dimensión |
| ángulo | `tora-telo` | cambio de dirección (sustituye a `ango`) |
| eje | `loka-mede` | línea de medida (sustituye a `akso`) |

> **Ángulo:** la guía PDF usaba `ango`, que no es pronunciable en Owee (grupo `ng`). Se sustituye por el compuesto **`tora-telo`** («cambio de dirección»): un ángulo mide cuánto cambia la dirección entre dos líneas. Se mide en grados (símbolo °).

### 6.1 Perímetro y área (`sufa mede`)

**Rectángulo de 5 por 3:** perímetro [[2 × 5 + 2 × 3 = 16]]; área [[5 × 3 = 15]].

**Cuadrado de lado 4:** perímetro [[4 × 4 = 16]]; área [[4 ^ 2 = 16]].

**Triángulo de base 6 y altura 4:** área = base × altura ÷ 2: [[6 × 4 ÷ 2 = 12]].

**Círculo (`selo`) de radio 3:** circunferencia `#C = 2πr = 2 × 3,1416 × 3 ≈ 18,85`; área `#A = πr² = 3,1416 × 9 ≈ 28,27`.

### 6.2 Volumen (`bola`)

**Caja de 4 × 3 × 2:** [[4 × 3 × 2 = 24]]. **Cubo de lado 3:** [[3 ^ 3 = 27]].

### 6.3 Ángulos

Los ángulos de un triángulo suman 180°: si dos miden 60° y 70°, el tercero mide [[180 − 60 − 70 = 50]] grados. Un ángulo recto mide [[90]]°; un giro completo, [[360]]°.

### 6.4 Teorema de Pitágoras

En un triángulo rectángulo: `#a² + b² = c²`. Con catetos 3 y 4: [[3 ^ 2 + 4 ^ 2 = 25]], por tanto la hipotenusa es [[√25 = 5]].

## 7. Trigonometría
<!--vocab Matemáticas|Trigonometría-->

Se mantiene la notación sin(θ), cos(θ), tan(θ). En el discurso Owee: `shenu`, `kosu`, `taga`.

**En el triángulo rectángulo 3-4-5** (cateto opuesto 3, adyacente 4, hipotenusa 5):

| Razón | Cálculo | Valor |
|---|---|---|
| sin θ = opuesto ÷ hipotenusa | `#3 ÷ 5` | `#0.6` |
| cos θ = adyacente ÷ hipotenusa | `#4 ÷ 5` | `#0.8` |
| tan θ = opuesto ÷ adyacente | `#3 ÷ 4` | `#0.75` |

Valores clásicos: sin 30° = `#1/2` · cos 60° = `#1/2` · tan 45° = `#1`. Identidad fundamental: sin²θ + cos²θ = 1; en el ejemplo, [[0.6 ^ 2 + 0.8 ^ 2 = 1]].

## 8. Cálculo
<!--vocab Matemáticas|Cálculo-->

| Concepto | Forma Owee | Nota |
|---|---|---|
| límite | `fese` | raíz general, especializada por contexto |
| cambio | `telo` | base de la tasa de cambio |
| tasa de cambio | `telo rata` | razón asociada al cambio |
| diferencial | `telo gore-po` | cambio pequeño; se conserva dx, dy |
| sumatoria | `dapa` + Σ | no necesita raíz nueva |

**Derivada (`dera`).** Si `#f(x) = x²`, entonces `#f′(x) = 2x`. En `#x = 3`: [[2 × 3 = 6]]. Para `#f(x) = x³`: `#f′(x) = 3x²`; en `#x = 2`: [[3 × 2 ^ 2 = 12]].

**Límite y secuencia.** La secuencia `sora` 1, 1/2, 1/4, 1/8, … se acerca al límite `fese` 0; la serie `geda` 1 + 1/2 + 1/4 + … tiene como límite `#2`. El infinito es `nufa`.

**Integral (`tega`).** `#∫ 2x dx = x² + C`. La integral definida da una **acumulación** (`koma`): `#∫ de 0 a 3 de 2x dx = 3² − 0² = 9`, o sea [[3 ^ 2 − 0 = 9]].

## 9. Estadística y probabilidad
<!--vocab Matemáticas|Estadística y probabilidad-->

| Concepto | Forma Owee | Nota |
|---|---|---|
| posibilidad | `pode` | concepto general: algo puede ocurrir |
| probabilidad | `laku` | medida matemática; **no** es sinónimo de `pode` |
| número aleatorio | `ranu banu` | |

**Ejemplo con datos `#2, 2, 3, 5, 8`:**

| Medida | Cálculo | Resultado |
|---|---|---|
| media (`baga`) | [[2 + 2 + 3 + 5 + 8 = 20]] y [[20 ÷ 5 = 4]] | `#4` |
| mediana (`neda`) | valor central de los datos ordenados | `#3` |
| moda (`foda`) | el valor que más se repite | `#2` |
| recorrido (dispersión, `desa`) | [[8 − 2 = 6]] | `#6` |

**Probabilidad.** `#0 ≤ P(A) ≤ 1`. Un dado de 6 caras: la probabilidad de sacar 4 es [[1/6]]; la de sacar un número par (3 casos de 6) es [[3/6]], o sea [[1/2]]. Una moneda: cara = [[1/2]].

## 10. Vectores y matrices
<!--vocab Matemáticas|Vectores y matrices-->

| Concepto | Forma Owee | Nota |
|---|---|---|
| componente | `dufa palo` | parte de un vector |
| escalar | `bema` + `no tora` | cantidad sin dirección |
| matriz 2×3 | `mata` con `du raga` y `ga kola` | |
| eje | `loka-mede` | sustituye a `akso` |

> **Eje:** la guía PDF usaba `akso` (grupo `ks`, impronunciable). Se sustituye por **`loka-mede`** («línea de medida»), en coherencia con `pose-mede` (coordenada). El eje de rotación en física es `loda-loka`.

**Longitud de un vector:** `#v = (3, 4)`; `#|v|² = 3² + 4²`: [[3 ^ 2 + 4 ^ 2 = 25]], por tanto `#|v| = 5`.

**Suma de vectores:** `#(1, 2) + (3, 4) = (4, 6)`; componente a componente: [[1 + 3 = 4]] y [[2 + 4 = 6]].

**Matriz 2×2:** `#A = [[1, 2], [3, 4]]` tiene [[2]] filas (`raga`) y [[2]] columnas (`kola`). **Determinante:** [[1 × 4 − 2 × 3 = −2]] (el resultado es negativo: `po du`; ver 3.5).

## 13. Correcciones y pendientes de auditoría

La guía PDF 2.0 usaba formas **impronunciables** en Owee (no existen `v` ni `i`, ni consonantes finales o grupos):

| Forma original | Problema | Forma vigente | Estado |
|---|---|---|---|
| `vara` (variable) | contiene `v` | `bara` | corregida (Física 2.0) |

| `dira` (dirección) | contiene `i` | `tora` | corregida |
