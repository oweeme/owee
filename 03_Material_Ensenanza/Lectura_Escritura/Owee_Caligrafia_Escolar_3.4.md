# Owee — cuaderno de caligrafía escolar (Owee Script 3.4)

Aprender viendo, repasando y repitiendo. En cada fila: **el modelo** (con su lectura), **tres copias claras** para repasar con el lápiz y **dos casillas vacías** para escribir sin ayuda.

**Cómo escribir bien Owee Script:**

1. Se escribe **en línea**, de izquierda a derecha.
2. Cada sílaba es la **consonante** (grande) y, a su **derecha**, la **marca de la vocal** (pequeña).
3. La vocal **no toca** la consonante.
4. Entre sílabas se deja **más aire** que dentro de una sílaba.
5. Puedes darle tu estilo (más redonda, más inclinada), pero cada letra tiene que **distinguirse** de las demás.

## 1. Las cuatro vocales

Cada vocal tiene **su forma**. No existe la i.

| Vocal | Forma | Para recordarla |
|---|---|---|
| `a` | barra de pie | una rayita, como un palito |
| `e` | viga エ | dos rayas y un palito entre ellas |
| `o` | anillo | un círculo pequeño y cerrado |
| `u` | runa ᚢ | un puente con una pata más corta |

## 2. Las consonantes por parejas

La consonante **sonora** es la misma forma **con una barra al medio**.

| Pareja | Forma | Diferencia |
|---|---|---|
| `pa` · `ba` | copa ⊔ | b = p + barra |
| `ta` · `da` | punta Λ | d = t + barra |
| `ka` · `ga` | esquina ┐ | g = k + barra |
| `fa` · `sa` | T · Z | formas distintas |
| `ma` · `na` | cuadro · círculo | m con raya de pie, n con raya acostada |
| `la` · `ra` | horquilla Y | r = l + punto |
| `sha` · `cha` | X · ✱ | ch = sh + raya de pie |

## 18. Palabras compuestas: el nexo

En un compuesto, el **nexo** ‿ (una curva baja) une las partes; en romano es el guion. Así `sade-kelo` (año) no se confunde con `sade kelo` (sol, ciclo).

<!--copiar sade-kelo suna-goda luma-salo meka-mado-->
