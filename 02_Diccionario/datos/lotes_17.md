# Lote 17 — términos de gramática (aprobados el 2026-10-22)

**26 términos** para hablar de la gramática en Owee (vocativo, demostrativo, cuantificador, acento, puntuación, pronombre…), necesarios para traducir al Owee los títulos y las reglas de la Gramática 1.1. Pasaron la verificación (sin colisiones ni dos palabras con el mismo significado) y la revisión de paralelismo: se cambiaron cinco formas que quedaban a una letra de otra del mismo tema (por ejemplo, `reme-reka` saludo y `rela-reka` conjunción; `rela-reka-palo` quedó para conjunción). Siguen siendo vecinas, a propósito, `foma-ba` (excepción) y `foma-ko` (normal), pares de la misma familia `ba`/`ko` (fuera de / con).

| Forma | Significado | Partes | Inglés |
|---|---|---|---|
| `sena-nara-reka` | **vocativo** — comunicación con el nombre de la persona | `sena` (signo) + `nara` (persona) + `reka` (comunicación) | vocative |
| `le-lu-reka` | **demostrativo** — palabra de cerca y lejos | `le` (cerca) + `lu` (lejos) + `reka` (comunicación) | demonstrative |
| `bema-reka-palo` | **cuantificador** — palabra de cantidad | `bema` (cantidad) + `reka` (comunicación) + `palo` (parte) | quantifier |
| `no-reka` | **negativo** — palabra de negación | `no` (negación) + `reka` (comunicación) | negative word |
| `reka-palo-rela` | **compuesto** — palabra unida | `reka` (comunicación) + `palo` (parte) + `rela` (unión) | compound word |
| `rela-sena` | **guion** — signo de unión | `rela` (unión) + `sena` (signo) | hyphen |
| `nuse-sena` | **espacio** — signo vacío | `nuse` (vacío) + `sena` (signo) | space |
| `sone-faro` | **acento** — fuerza del sonido | `sone` (sonido) + `faro` (fuerza) | stress |
| `faro-bema` | **intensidad** — cantidad de fuerza | `faro` (fuerza) + `bema` (cantidad) | intensity |
| `se-mede` | **comparación** — medir la igualdad | `se` (igualdad) + `mede` (medir) | comparison |
| `ka-reka-palo` | **interrogativo** — palabra de pregunta | `ka` (pregunta) + `reka` (comunicación) + `palo` (parte) | interrogative |
| `ra-rela` | **relativo** — unión con ra | `ra` (él) + `rela` (unión) | relative pronoun |
| `reka-fese-rela` | **subordinación** — oración unida | `reka` (comunicación) + `fese` (límite) + `rela` (unión) | subordination |
| `reme-reka` | **saludo** — comunicación de amistad | `reme` (amistad) + `reka` (comunicación) | greeting |
| `reme-lena` | **cortesía** — amistad agradable | `reme` (amistad) + `lena` (agrado) | courtesy |
| `sone-nuse-sena` | **puntuación** — signos del silencio | `sone` (sonido) + `nuse` (vacío) + `sena` (signo) | punctuation |
| `reka-palo-ba` | **préstamo lingüístico** — palabra de fuera | `reka` (comunicación) + `palo` (parte) + `ba` (exterior) | loanword |
| `dore-tada` | **choque de formas** — contacto de formas | `dore` (forma) + `tada` (contacto) | form clash |
| `rela-kare` | **coherencia** — unión correcta | `rela` (unión) + `kare` (corrección) | coherence |
| `soma-dese` | **propuesta** — idea para decidir | `soma` (idea) + `dese` (decisión) | proposal |
| `foma-ba` | **excepción** — fuera de la regla | `foma` (regla) + `ba` (exterior) | exception |
| `nara-reka-palo` | **pronombre** — palabra de persona | `nara` (persona) + `reka` (comunicación) + `palo` (parte) | pronoun |
| `rela-reka-palo` | **conjunción** — palabra de unión | `rela` (unión) + `reka` (comunicación) + `palo` (parte) | conjunction |
| `reka-palo-fese` | **modificador** — palabra que limita | `reka` (comunicación) + `palo` (parte) + `fese` (límite) | modifier |
| `gura-kema` | **objeto gramatical** — objeto que recibe | `gura` (recibir) + `kema` (objeto) | grammatical object |
| `dare-nara` | **sujeto gramatical** — persona que hace | `dare` (hacer) + `nara` (persona) | subject |
